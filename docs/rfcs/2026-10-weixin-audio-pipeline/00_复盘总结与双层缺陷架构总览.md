> **归档时间**：2026-10-15  
> **复盘环境**：腾讯云新加坡轻量服务器 (`43.133.57.17`)，运行 Hermes Agent (`v0.22+`)，网关平台为微信 iLink 个人号协议 (`gateway/platforms/weixin.py`)。  
> **归档目的**：为后续强力 Coding Agent 承接上游 GitHub Issue / PR 提供完整的工程级事实、现场证据链与重构设计（RFC）。

## 核心发现：两层异质缺陷的连环爆发

在针对一首 3 分 11 秒（4.9MB M4A 格式）音乐文件进行端到端发送与音乐学分析测试时，系统先后在**平台传输层**与**框架多模态感知层**连环爆发了两个性质截然不同的架构级缺陷：

```text
[ 用户端：微信发送 M4A 音频附件 (4.9MB) ]
                │
                ▼
┌─────────────────────────────────────────────────────────────┐
│ 🔴 问题一：微信平台传输层缺陷 (gateway/platforms/weixin.py)    │
│  - 链接优先级倒置导致海外节点直连国内特定电信 CDN (丢包率>30%) │
│  - 硬编码 60 秒超时掐断、aiohttp 事件循环流式读取阻塞死锁   │
│  - 失败时静默吞噬用户消息 (if not text and not media: return) │
│  - 内存临时 AES-128 解密密钥随异常抛出销毁，无法断点重试     │
└──────────────────────────────┬──────────────────────────────┘
                               │ (已通过现场热补丁打通下载并固化凭据)
                               ▼
┌─────────────────────────────────────────────────────────────┐
│ 🔴 问题二：Hermes 全局音频管线缺陷 (gateway/run.py 等核心模块)  │
│  - 越权强制拦截：MIME 为 audio/* 无脑判定为“语音条”强行 STT  │
│  - 本地 74M 小 Whisper 模型崩塌，产生灾难级多语种听觉幻觉     │
│  - 回显污染与上下文暴力篡改：将幻觉回显到微信，并抹除原文件路径 │
│  - 多模态架构断代：图片/视频均有原生支持，唯独音频完全无原生工具│
└──────────────────────────────┬──────────────────────────────┘
                               │ (绕过网关 STT，直传 Gemini 3.8 Flash)
                               ▼
[ 验证成功：大模型原生音频编码器精准解码调性/BPM/多语种歌词/编曲 ]
```

## 资料库文件索引与分工

本文件夹包含完整的现场还原与技术设计，按模块拆解如下：

1. **`[[01_问题一_微信下载链路缺陷与证据链]]`**：
   - 记录微信渠道在下载阶段的完整时序日志（18:06 至 18:40）；
   - 提取真实崩溃堆栈（`readany()` 阻塞、`TimeoutError`）；
   - 剖析 6 大具体根因代码，并附上验证有效的 Git Unified Diff 补丁；
   - 留存微信下发的真实元数据与凭据载荷 (`raw_evidence/last_inbound_media.json`)。
2. **`[[02_问题二_音频管线越权劫持与模型幻觉实证]]`**：
   - 详细记录 Whisper `base` 将韩语歌曲识别为离谱英文的“幻觉事件”全过程；
   - 源码走查：`run.py` 如何拦截、`run_inbound.py` 如何覆盖输入并隐匿文件路径；
   - 给出**决定性对比实验**：本地 Whisper 幻觉文本 vs 直传 Gemini 3.8 Flash 原生音频理解的实测报告与脚本。
3. **`[[03_三模态管线全景横向审计_图片_视频_音频]]`**：

   - 揭示音频管线“十年前单向对讲机偏见”的技术成因。
4. **`[[04_下一代Agent重构实施蓝图_RFC]]`**：
   - 为接替的 Coding Agent 提供清晰的 Step-by-Step 实施步骤；

5. **`[[05_上游社区现有Issue与PR调研对比]]`**：
